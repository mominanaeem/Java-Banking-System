# AEM - Banking Management System

AEM is a Java-based Banking Management System developed as a university group project. It was built to practice Object-Oriented Programming (OOP) principles and database integration.

**How it works:**
- The application is built using Java and connects to a relational database.
- It uses JDBC (via the UCanAccess library) to communicate with an MS Access database.
- The app handles core banking operations like account management and secure transaction processing.

**Files included in this repo:**
- `OOP_Project_GUI.jar`: The executable application. You can run this to see the GUI and use the app.
- `oop8.accdb`: The MS Access database file that stores the user and transaction data.

*(Note: The Java source code files are not included in this repository. The files above are provided to demonstrate the final working application and database structure.)*
